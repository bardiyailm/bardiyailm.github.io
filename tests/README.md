# اختبارات بردية علم

فحوص آلية بـ Playwright تُشغَّل قبل أي نشر:

| الملف | ما يفحصه |
|---|---|
| `audit.js` | رسم كل الأقسام على الهاتف والحاسوب بلا أخطاء ولا تجاوز أفقي |
| `a11y.js` | أسماء الأزرار والحقول لقارئ الشاشة |
| `xss.js` | عدم تنفيذ شيفرة محقونة في الحقول النصية |
| `sync.js` | أن كل مفاتيح البيانات تُرفع للسحابة (لا مفاتيح بأحرف كبيرة) |
| `fuzz.js` | 1000 خطوة عشوائية بلا أخطاء ولا تسرّب |
| `mind.js` | توليد اختبار العقل: اكتمال العدد، بلا تكرار داخل الاختبار ولا مع الأسابيع السابقة |
| `verify.js` | صحة إجابات مولّدات الذكاء باشتقاق مستقل من نص السؤال (٥٬٦٠٠ تحقّق) |
| `mindflow.js` | دورة الاختبار: البدء، المؤقّت، الاستئناف، التصحيح، المرتبة، منع التكرار الأسبوعي |
| `mindboard.js` | قائمة المراكز: سؤال المشاركة، الإرسال، عرض الترتيب |

التشغيل: `npm i playwright` ثم `(python3 -m http.server 8765 &) && bash tests/run.sh`
